 Night Shift — Unity C# Source Code



Night Shift is a short, retro-inspired 3D horror game developed in Unity in under 20 days.



This repository contains the game's original C# gameplay scripts, organized by system. It serves as a programming portfolio showcase rather than a complete Unity project.



[Play Night Shift on itch.io](https://alastair-960.itch.io/night-shift)\*\*






 Game Overview



Night Shift combines customer interactions, crafting mechanics, environmental exploration, and enemy encounters.



The project focuses on integrating several gameplay systems into a complete, playable horror experience within a short development period.



 Implemented Systems


Enemy AI

Enemy roaming and navigation.

Investigation behavior.

Player detection and chase behavior.

Enemy animation and audio integration.



Customer System

Customer interactions and order handling.

Customer appearance randomization.



Interaction \& Puzzle Systems

Interactive environmental objects.

Code-based puzzles and locks.

Puzzle clues and player interaction mechanics.



Player Mechanics

Player interaction systems.

Flashlight and battery mechanics.

Battery pickups and resource management.



Additional Systems

Basic crafting mechanics.

Gameplay managers and state handling.

User interface elements.

Gameplay audio systems.







Source Code Organization



The `Scripts/` directory contains the following categories:



| Folder | Purpose |

|---|---|

| `Audio/` | Audio-related gameplay scripts |

| `BackroomsScripts/` | Scripts associated with the Backrooms sequences |

| `Customers/` | Customer-related mechanics |

| `Enemies/` | Enemy AI and related behavior |

| `Interactables/` | Interactive objects and mechanics |

| `Managers/` | Gameplay management systems |

| `Night2Scripts/` | Scripts associated with the second night |

| `Player Scripts/` | Player mechanics |

| `UI/` | User interface functionality |

\## Important Notes



This repository contains gameplay source code only.



The complete Unity project is not included because it uses third-party models, textures, audio, and other assets.



As a result, the scripts are provided for inspection and reference and are not intended to function as a standalone, directly compilable game.
